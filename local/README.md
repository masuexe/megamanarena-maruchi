# `local/` Workspace Directory (Clean-Room Local Assets & Build Outputs)

To prevent DMCA / copyright issues and avoid checking large release binaries into Git, **all files and subdirectories created inside `local/` are git-ignored**. Only `local/README.md` and `local/README.zh-CN.md` are tracked in Git so that `git clone` automatically prepares the `local/` directory structure with clear instructions.

## Choose Your Workflow

### 1. Native Headless Server Only (`Mma.Server`) — Stock Game Archive NOT Required
If you only want to build or host the cross-platform `.NET 10` headless server (`win-x64` for Windows / Windows Server and `linux-x64` for Linux), you do **not** need `MegaManArena_v5.0.0.zip`.

Run from the repository root:
```powershell
.\scripts\Publish-Server.ps1
```

Outputs created here:
- `local/dist/` — Ready-to-share server archives (`megamanarena-server-win-x64.zip`, `megamanarena-server-linux-x64.tar.gz`, `SHA256SUMS.txt`).
- `local/publish/win-x64/` & `local/publish/linux-x64/` — Unpacked self-contained single-file server folders for local testing.

### 2. GML Patches & Game Client (`Arena8` / `DedicatedServer`)
If you also want to build the patched `.win` data files (`Arena8` 8-player client or legacy 4-player Windows GameMaker server patch) or run live local game clients:
1. Place your legitimate copy of **`MegaManArena_v5.0.0.zip`** directly in `local/MegaManArena_v5.0.0.zip` (or extract it elsewhere and set `$env:MMA_GAME_DIR`).
2. Run from the repository root:
   ```powershell
   .\scripts\Setup-DevEnv.ps1
   ```

This populates the following git-ignored subdirectories:
- `local/game/` — Extracted stock *Mega Man Arena 5.0.0* game directory (`data.win` verified by SHA-256).
- `local/tools/` — Downloaded `UndertaleModCli v0.9.2.0` toolchain.
- `local/build/` — Patched `.win` outputs (`DedicatedServer/data.server.win`, `Arena8/data.client8.win`, `Arena8/data.server8.win`).
- `local/decompiled/` — Local GML reference exports generated by `.\scripts\Export-OnlineGml.ps1`.
- `local/runtime/` — Isolated local launch copies reusing `Music/` and `SFX/` via NTFS junctions.
